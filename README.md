# Student Management System

A C++ based Student Management System for managing student information.

## Features

* Add student records
* Display student records
* Search for students
* Update student information
* Delete student records

## Requirements

Before running the project, make sure you have:

* C++ compiler
* VS Code (recommended)
* Git (optional, only required for downloading/updating the project)

## Installation

### 1. Clone the repository

Open a terminal and run:

```bash
git clone https://github.com/spulkit026/Student-Management-System.git
```

### 2. Open the project

Go into the project directory:

```bash
cd Student-Management-System
```

Open the project in VS Code:

```bash
code .
```

## How to Run

Compile the C++ program using:

```bash
g++ main.cpp -o main
```

Then run it:

### macOS / Linux

```bash
./main
```

### Windows

```bash
main.exe
```

## Example

After running the program, follow the options displayed in the terminal to manage student records.
